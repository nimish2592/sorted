# Sorted

**Company paperwork, sorted.**

Records and compliance for Indian Private Limited companies — built for VNS Labs.

## App

```bash
cd sorted
cp .env.example .env.local   # fill secrets
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

Production: [https://sorted.clipera.in](https://sorted.clipera.in)

## Stack

Next.js · TypeScript · Tailwind · Google Drive + Sheets (server-side OAuth)
